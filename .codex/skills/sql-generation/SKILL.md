# SQL 生成

- 禁止在生成或修改的 SQL 中使用 `DATABASE()` 函数。需要指定数据库时，使用已确认的数据库名；数据库名未知时向用户询问。
- 生成或修改代码内的 SQL 时，直接在普通回复中提供对应的 `EXPLAIN` 语句，让用户执行并回传结果；此时使用可复制的 SQL 代码块，不使用交互式询问工具或选择卡片。
- 代码 SQL 的执行计划不符合预期时，在换查询方案和修改索引之间直接选择更合理的一种，结合实际执行计划及索引信息说明选择，并提供调整后的方案及对应的 `EXPLAIN`。
- 排查问题时，直接提供带 `/*+ MAX_EXECUTION_TIME(300) */` 的查询供用户执行，不要求 `EXPLAIN`。该提示用于支持它的数据库版本及只读 `SELECT`，放在首个 `SELECT` 后，限制执行时间为 5 秒。
- 排查过程中，用户报告查询超时时，应更换查询方案并继续提供限时查询，不以修改索引作为解决方案。
- 同次回复需要用户执行的 SQL 超过两条时，将这些语句按执行顺序合并到一个可复制的 SQL 代码块，方便用户一次性复制执行。
