# 技能编写规则

编写有助于决策且保留用户意图的技能。创建、修改和检查均手工完成，禁止执行脚本。

## 内容与范围

- 默认 Agent 已具备通用能力，只写能改变决策或改善结果的信息
- 保留必要知识、约束和有效示例，删除泛泛建议、重复指令和猜测性的边界情况
- 保留用户选择的产品、任务范围和授权边界，任务授权不扩大执行权限
- 不擅自增加外部操作或修改无关配置，不将单个案例、历史失败或个人偏好泛化为通用要求
- 重试或外部变更流程应有与风险相称的停止条件
- 专项审查、加固和审计仅在用户要求或确有需要时适用

## 约束强度

- 开放任务写清目标和判断标准，保留方法选择空间
- 仅在正确性、安全、权限或易错流程需要时，规定详细步骤、固定顺序和严格参数
- 保留关键约束，区分硬性要求、可选建议和本地惯例，避免重复已在其他位置执行的规则

## 命名与触发

- 技能名使用小写字母、数字和连字符，少于 64 个字符，简短且体现动作，文件夹与技能同名
- 仅在有助于发现时，按工具或领域区分名称
- frontmatter 必须包含 name 和 description，按需保留 metadata 等受支持字段
- description 简述能力与适用场景，仅为防止误触发补充排除边界，避免过宽描述和穷举清单
- 详细流程、工具选择、操作模式和大量示例放在正文或引用文档中

## 内容与资源组织

- SKILL.md 保留共同目标、必要约束、核心流程和引用入口，篇幅以保留关键约束为限
- 名称与描述用于选择技能，正文在适用时读取，支持资源按需读取
- 多种模式各有大量内容时，将专用知识分入引用文档，入口说明选择条件
- 技能包含 SKILL.md 和 agents/openai.yaml，其他支持资源按需增加
- 技能尽量自包含，仅在流程确实依赖且环境可用时引用其他技能或工具
- 引用文档存放场景专用知识，由入口或其他资源链接并说明读取时机，当前任务只读适用内容
- 信息集中维护，引用应与任务直接相关且可维护，避免重复、整套手册、穷举目录和通用教程
- 长引用按需提供简短目录或检索词
- 素材用于最终产物，仅在任务需要检查时读取
- 目录、模板、示例和辅助文档须有明确用途，说明书、安装指南和变更记录仅按任务或交付要求添加
- 删除已有资源前，检查用途和引用关系

## 界面元数据与调用策略

- 新建技能必须创建 agents/openai.yaml，至少包含 interface.display_name、interface.short_description 和 interface.default_prompt
- 创建或修改 agents/openai.yaml 时，读取 [界面元数据格式](references/openai_yaml.md)，保持字段与技能一致
- 仅修改目标字段，保留无关界面、策略和依赖字段，可选界面字段仅在用户提供或要求时加入
- 默认允许自动选择，仅在用户明确要求时改为只允许显式调用，已有策略按用户要求修改
- 敏感操作或审批要求不构成关闭自动选择的理由，在实际变更前处理授权
- 调用模式不明确且影响流程时才提问

## 创建与修改

- 按请求规模开展工作，局部修改采用局部编辑，新建或大幅修改结合真实场景设计
- 尊重用户指定位置，否则使用 `$CODEX_HOME/skills`，未设置 CODEX_HOME 时使用 `~/.codex/skills`
- 仅在缺失信息影响结果且不能合理推断时提问，信息足够时直接推进
- 手工创建和编辑必要文件，支持资源须有具体收益，保留已有受支持字段和用户明确选择
- 只写完成任务所需的目标、背景、约束和资源，不强加任务不需要的结构、流程或步骤数量

## 人工检查与迭代

- 人工检查 frontmatter、命名和未完成的占位内容
- 新建技能交付前检查 SKILL.md 和 agents/openai.yaml 均已创建，并核对界面名称、简短说明和默认提示与技能内容一致
- 检查描述的区分度、用户意图与授权边界是否保留、引用是否易于发现
- 检查新增文件用途，删除重复和无关内容
- 结构检查不能证明决策正确，有必要时验证可观察行为和关键约束，不只匹配措辞、标题或正则模式
- 根据真实使用或已证明的问题局部修正，避免为每个案例积累通用限制

## 独立行为验证

- 复杂度或风险足以使行为验证带来实际收益，且委派可用并已获授权时，使用独立 Agent，普通创建或小改动不自动要求委派
- 提供真实请求、技能和最少必要原始材料，非必要不提供预期答案、疑似问题、拟议修复或既有结论
- 限于已授权资源与副作用，产物放入隔离临时工作区，防止影响工作树或后续验证
- 需要额外授权、影响生产系统或产生显著时间与费用成本时，先取得批准
- 检查实际结果与产物，仅按观察到的行为修改技能
