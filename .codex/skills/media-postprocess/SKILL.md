# 图片、音频、视频后处理

- 后处理应去除所有可去除的元数据，检查文件、流、章节及其他实际存在的元数据位置，并在处理后核对结果。
- 图片应去除包括方向信息在内的元数据；先将方向信息应用到像素，保持显示方向正确，再删除方向信息。
- 音频保留 `TITLE`、`ALBUM`、`ARTIST`、`album_artist`，四项均必须存在且有值；按格式识别对应标签。缺失或为空时，先向用户确认如何补充，保留已有值，清理其余可去除的元数据。
- 视频保留编码器信息，以及当前输出格式由 FFmpeg 默认生成的容器、流描述信息，包括 `major_brand`、`minor_version`、`compatible_brands`、`encoder`、`handler_name`。使用实际输出对应的值；从输入复制的元数据不等同于默认生成的信息，其余可去除的元数据均应删除。
- 删除前自行判断是否会影响解码、显示、播放或其他既有功能；除上述明确保留项外，若判断删除可能出问题，先说明具体影响并向用户确认如何处理。
